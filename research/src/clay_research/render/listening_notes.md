# Phase 1 listening set: WORLD pitch shifting

Each folder is one vocal. Play `00_original` first, then the others.

| File | What it is | Listen for |
|---|---|---|
| `00_original` | The untouched recording | Reference |
| `01_resynth_no_edit` | Rebuilt by WORLD with **no** edit | WORLD's own sound: any buzz, phasiness, or dullness here is the vocoder, not the editing |
| `02`–`05` | Whole vocal shifted ±1 and ±2 semitones, formants preserved | Does it still sound like the same singer? Artifacts on held notes, breathy parts, consonants ("s", "t") |
| `06` | +2 semitones with formants moved too | What formant preservation saves you from (compare with `04`) |

All WORLD versions are level-matched to the original.

**The Phase 1 gate question:** at ±2 semitones (`04`, `05`), are there any *objectionable* artifacts?
Reply per vocal: OK / minor / objectionable, plus anything specific you hear.
